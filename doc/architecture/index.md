# CDD Repository Architecture

How this repo is structured. This index is a pointer list — the content lives in the per-topic documents.

## Documents

- [Overview](overview.md) — the two-layer model (process doc + template), top-level layout, layer relationships, the consistency guards and the check runner (`scripts/ci.sh`), open structural questions
- [Bootstrap & retrofit](bootstrap-and-retrofit.md) — the single substitution pipeline: bootstrap script, stage mode, overlay mode, `/cdd-bootstrap`, `/cdd-retrofit`, the baseline marker
- [Shell helpers](shell-helpers.md) — how `cdd-worktree` and `cdd-state` are installed and wired: install model, PATH shims, runtime derivation, atomic state writes, the `x-` extension namespace, the per-repo marker, resume discovery, code-host adapter resolution at each helper call site
- [The demo layer](demo.md) — the third artifact: filled-in seed + create/teardown automation
- [Capability adapters](capability-adapters.md) — the wire contract for `.cdd/` adapters, pinned for the tracker and code-host capabilities: their verbs and JSON shapes, the exit-code table, `describe` and its `contract` versioning rule, the GitHub reference adapters, the Jira and GitLab adapters, the "Installing a binding" section, the resolution ladder's broken-adapter rule and the announcement rule, and what the offline conformance gate does and does not prove
- `adr/` — architecture decision records (`adr/0000-template.md` for the format)
  - [`0001-name-and-guard-founding-objectives.md`](adr/0001-name-and-guard-founding-objectives.md) — naming and guarding CDD's two under-guarded founding objectives (engineering practices, self-improvement)
  - [`0002-scope-prompt-seam-checks-deterministic-only.md`](adr/0002-scope-prompt-seam-checks-deterministic-only.md) — scoping prompt "CI" to deterministic seam checks; why LLM-as-judge evals (and a generalized prompt-lint framework) are not planned work
  - [`0003-standing-self-improvement-channel.md`](adr/0003-standing-self-improvement-channel.md) — the recurring channel behind commitment 5: a conditional `/cdd-pre-pr` step plus a `/cdd-process-pr` triage route, their trigger design, and why an upstream candidate becomes a GitHub issue rather than a local roadmap item or a standing log
  - [`0004-conditional-merge-base-approval.md`](adr/0004-conditional-merge-base-approval.md) — making human checkpoint 4 conditional: the four mechanical criteria for an automatic `/cdd-merge-base`, why no "mechanical conflict" auto-resolve tier exists, and the residual semantic-break risk
  - [`0005-roadmap-item-length-cap.md`](adr/0005-roadmap-item-length-cap.md) — one 200-character cap for every roadmap item, pending and completed alike, enforced by the `roadmap-length` gate; where detail goes instead (a GitHub issue or the handoff), and why neither a separate backlog document nor a `Status: Proposed` ADR is that place
  - [`0006-small-change-lane.md`](adr/0006-small-change-lane.md) — the second lane through the middle of the cycle: `/cdd-small-change` in place of plan + implement, the recorded lane marker and its one-directional degrade, the one-sentence eligibility heuristic and its off-ramp, and why the checkpoint count stays six
  - [`0007-extend-cdd-through-capability-adapters.md`](adr/0007-extend-cdd-through-capability-adapters.md) — extending CDD through capability adapters: the fixed `.cdd/` namespace and its mandatory `describe` verb, the project → machine resolution ladder (its built-in third rung dropped by 0012), the replace-vs-mirror rule bounding what an extension may substitute, and the shortlist verdict (GitHub reference adapter first, then Jira and GitLab); partially superseded by 0009, 0010 and 0012
  - [`0008-drop-the-issue-ref-branch-token.md`](adr/0008-drop-the-issue-ref-branch-token.md) — dropping the `gh_issue_NN_` branch token so the task state record is the only carrier of a task's issue references; why a backend-agnostic token format is more mechanism rather than less, and the two costs accepted in exchange (no close lines when the record is unusable, a wider browse-mode blind spot)
  - [`0009-drop-the-docs-capability.md`](adr/0009-drop-the-docs-capability.md) — withdrawing the docs capability: an adapter is justified only when a CDD script or structured workflow step consumes the backend's output; docs are served by each project's own MCP server plus a `CLAUDE.md` line, and Linear and Slack are judged by the same rule
  - [`0010-code-host-rename-and-broken-adapter-rule.md`](adr/0010-code-host-rename-and-broken-adapter-rule.md) — renaming the "forge" capability to "code host", and the ladder's three cases for every capability: a missing adapter falls through (until 0012), an installed-but-broken one stops with one line naming it (never a lower rung), an unsupported verb skips the feature; per-call-site stop reach, and the helpers' silent built-in rung (dropped by 0012)
  - [`0011-bind-adapters-through-a-machine-global-library.md`](adr/0011-bind-adapters-through-a-machine-global-library.md) — how an installer binds a project to a shipped adapter: `cdd-worktree.sh install` copies the adapters to a machine-global library that is not a ladder rung, and the committed `.cdd/<capability>` shim execs it through `$HOME`; a missing library is a broken adapter; the installers write the project rung only, never a secret
  - [`0012-drop-the-builtin-gh-rung.md`](adr/0012-drop-the-builtin-gh-rung.md) — dropping the built-in `gh` rung now that installers bind adapters: the ladder ends at "nothing", a missing adapter skips the feature with one `/cdd-retrofit` line (or stops where the feature is the invocation's point), per-call-site behaviour for the prompts and `done`/`gc`/`list`/`resume`, and the read-only adapter verbs that replace the `gh` settings allowlist
  - [`0013-same-list-same-scripts-and-host-tool-portability.md`](adr/0013-same-list-same-scripts-and-host-tool-portability.md) — the runner's guarantee is "same list, same scripts", not "same command": CI may fan out over the runner's list mode, and host tools can still differ; narrowed by the `portability` gate and a two-OS (Ubuntu + macOS) CI matrix; CDD requires bash >= 4; a missing tool fails its gate, never skips it, locally and in CI
